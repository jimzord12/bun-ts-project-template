# Bun + TypeScript HTTP API Starter

A GitHub template for small-to-medium JSON APIs. The design includes a runnable,
authenticated Todo API and practical playbooks for maintainers and coding agents.

**Status** — Design in progress. This repository is a planning checkpoint.
