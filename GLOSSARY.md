# Bun + TypeScript HTTP API Starter

A GitHub template for small-to-medium JSON APIs.

## Language

**Milestone**:
A first-level deliverable in the template design. Each milestone has a defined outcome and can be broken down into smaller decisions and deliverables.

**Work Type**:
A category of work defined by its intended outcome and the evidence needed to assess it.

**Bug**:
Work to correct a gap between expected and observed behavior.

**Feature**:
Work to add or deliberately change supported behavior.

**Maintenance**:
Work to improve or sustain the project while preserving intended product behavior.

**Spike**:
A timeboxed investigation that gathers evidence for a decision.

**Report**:
An incoming description of a problem, request, or discovery that can be evaluated during triage.

**Triage**:
The evaluation of a report or task to determine its type, priority, and readiness.

**Ready**:
A task whose outcome, scope, and verification are clear and whose blockers to starting have been resolved.

**Blocker**:
An unresolved condition that prevents a task from starting or completing.

**Task Feedback**:
An agent's account of friction encountered during a task, including its impact and a proposed fix or open question.
